How it works

  1. Open kickFile on both devices, on the same Wi-Fi or your phone's hotspot. They find each other by themselves (or scan a QR code).
  2. Pick files and tap the other device. On a computer, drag files onto it.
  3. The first time, check that both screens show the same 6-digit code, then trust the device. Files go straight across your local network, encrypted.

Watch the 3-minute how-to video

First time on a Mac

kickFile isn't notarised by Apple yet, so macOS blocks the first launch. Open it once, then go to System Settings › Privacy & Security and click Open Anyway. Allow it to find devices on your local network when asked.

First time on Windows

Run the installer (or unzip the zip anywhere and run kickfile.exe). If SmartScreen warns about an unknown app, choose More info › Run anyway. Allow kickFile through the firewall on private networks.
